# CodeEdit

CodeEdit 是一款面向 Windows 桌面的轻量级多项目代码编辑器。它把项目文件树、代码编辑器、文件预览和多终端工作区放在一个窗口里，适合日常查看项目、编辑代码、运行命令和快速处理多项目任务。

## ✨ 功能亮点

- 📁 多项目管理：可以同时打开多个项目文件夹，并在左侧文件树中统一浏览。
- 🧠 项目记忆：关闭应用后会记住已打开的项目文件夹，下次启动自动恢复。
- 🔎 文件名搜索：在 Explorer 顶部搜索所有已添加项目中的文件名，大小写不敏感。
- 🧩 多标签编辑：打开的文件会以标签页形式展示，支持切换和关闭。
- 🎨 代码高亮：基于 Monaco Editor，支持 Java、JavaScript、TypeScript、JSON、HTML、XML、CSS、Python、Go、Rust、SQL、Markdown 等常见语言。
- ☕ Java 增强高亮：对 Java 的注解、修饰符、控制流、类型、方法调用、Javadoc、字符串块等做了更细致的颜色区分。
- 💡 明暗主题：内置深色和浅色两套主题，可通过灯泡按钮或菜单切换。
- 📝 Markdown 预览：`.md` 文件支持编辑、编辑+预览、纯预览三种模式。
- 🖼️ 图片/PDF 预览：图片和 PDF 可以直接在编辑器中查看。
- 📄 Office 文件支持：Word、Excel、PPT 等文件会调用系统默认应用打开。
- 🖥️ 内置终端：集成命令行终端，支持创建多个终端。
- 🧱 终端网格：多个终端可以横向拼合；超过 4 个后自动变成两行网格布局。
- ↕️ 可调布局：编辑区和终端区之间的分隔条可以拖动，按需调整空间。
- 🗂️ 系统资源管理器：右键文件夹可直接在 Windows 文件资源管理器中打开。

## 🚀 基本使用

### 📂 打开项目

启动应用后，可以通过以下方式打开项目文件夹：

- 点击欢迎页中的“打开项目文件夹”
- 点击左侧 Explorer 底部的“添加项目”
- 使用菜单中的“文件 -> 打开文件夹...”

打开后的项目会显示在左侧文件树中。应用会记住这些项目，下次启动时自动恢复。

### ✍️ 编辑文件

在文件树中点击文件即可打开编辑。文本和代码文件会进入编辑器标签页，支持语法高亮和保存。

常用操作：

- `Ctrl + S`：保存当前文件
- `Ctrl + Shift + S`：保存全部已修改文件
- `Ctrl + W`：关闭当前文件

### 🔍 搜索文件

Explorer 标题旁有搜索框，可以在所有已打开项目中搜索文件名。搜索不区分大小写，点击结果会直接打开对应文件。

### 🖥️ 使用终端

点击“显示终端”或通过菜单打开终端区域。可以创建多个终端，多个终端会在底部区域拼合显示。

终端区域支持：

- 新建终端
- 关闭终端
- 点击终端窗格切换焦点
- 拖动上方分隔条调整终端高度
- 超过 4 个终端后自动两行排布

### 💡 切换主题

应用支持深色和浅色主题。

切换方式：

- 点击顶部灯泡按钮
- 使用菜单“视图 -> 切换明暗主题”
- 使用快捷键 `Ctrl + Shift + L`

### 👀 预览文件

CodeEdit 会根据文件类型选择合适的打开方式：

- 图片：在编辑器内预览
- PDF：在编辑器内预览
- Markdown：可切换编辑、编辑+预览、预览模式
- Word / Excel / PPT：使用系统默认应用打开

## 🧭 适用场景

- 同时查看多个项目目录
- 快速编辑代码和配置文件
- 在编辑器内运行项目命令
- 查看 Markdown、图片、PDF 等项目资料
- 在一个窗口中管理多个终端任务

## 📌 说明

CodeEdit 当前主要面向 Windows 桌面环境。部分文件类型会依赖系统默认应用或系统组件进行打开和预览。
